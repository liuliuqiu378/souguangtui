Python 最小语法：够读本项目就行

你不需要先学完一门编程课。下面这些覆盖了教程里 90% 的代码。

概念长什么样一句话理解
变量x = 3、name = "M001"给一个值起名字，后面用名字代替它
列表 / 字典[1, 2, 3]、{"a": 1}列表是一队值；字典是“键 → 值”的查找表
函数def f(x): return x * 2把一段操作包起来，给个名字，可重复调用
条件if x > 0: ... else: ...满足条件才执行某段
循环for i in range(3): ...对一组东西逐个做同一件事
导入import pandas as pd借用别人写好的工具箱，pd 是它的简称
缩进4 个空格Python 用缩进表示“属于上一行”，缩进错了逻辑就变了
最小示例：不装任何东西也能看懂
meters = ["M001", "M002", "M003"]
loads  = [120.5, 98.2, 210.0]

for m, p in zip(meters, loads):     # 把两个列表配对，逐个取
    if p > 150:
        print(m, "高负荷", p)
    else:
        print(m, "正常", p)
报错怎么读：只看最后一行

Python 报错一长串，真正有用的通常是最后一行：KeyError: 'p_kw' 表示列名不存在，ValueError: could not convert string to float 表示某列混进了文字，FileNotFoundError 表示路径不对。先照最后一行改，不要从头读。

pandas：把 Excel 的活写成代码

pandas 是 Python 里处理表格的库。你已经会的 Excel 操作，几乎都能一一对应。

Excel 里怎么做pandas 怎么写说明

一段完整的小例子（可直接运行）
import pandas as pd

df = pd.DataFrame({
    "meter_id": ["M001", "M001", "M002", "M002"],
    "ts": ["2024-08-01 00:00", "2024-08-01 00:15",
           "2024-08-01 00:00", "2024-08-01 00:15"],
    "p_kw": [120.5, 118.0, 210.0, 215.5],
})
df["ts"] = pd.to_datetime(df["ts"])

df["energy_kwh"] = df["p_kw"] * 0.25        # 15 分钟 → 电量
per_meter = df.groupby("meter_id")["energy_kwh"].sum()
print(per_meter)
# M001    59.625
# M002   106.375
新手最常见的三个错

① 列名拼错（多一个空格也算错）；② 忘了 parse_dates 或 to_datetime，时间列变成字符串，排序和画图都会乱；③ 直接 df["p_kw"] + 1 改原表，结果后面全被污染。遇到“结果不对”，先 print(df.head()) 看数据本身。

机器学习 12 个词，用一句话说清

词大白话在本项目里的例子
样本一条记录 / 一个例子某天 0 点对 1 点的负荷预测任务
特征用来判断的线索（输入）昨天同时刻负荷、温度、星期几
标签要预测的答案（输出）明天 1 点的实际负荷
模型从线索到答案的公式LightGBM 的那 183 棵树
训练用历史例子把公式调出来拿 2023~2024 年数据拟合
预测用调好的公式算新答案输入明天天气，输出 24 个点
损失预测和答案差多少MAE、MSE；越小越好
过拟合把历史背下来了，换新题就错训练集很好、测试集很差
欠拟合太笨，连历史规律都没学会训练集和测试集都差
正则化故意“收着点”，防止背题Ridge 的 L2、树的深度限制
超参数训练前人为设定的旋钮树的数量、学习率、叶子数
基线不用机器学习能做到的水平“昨日同期”MAPE 5.30%
5 行看懂“训练”和“预测”
from sklearn.linear_model import LinearRegression

X = [[1], [2], [3], [4]]    # 特征（比如温度）
y = [2, 4, 6, 8]              # 标签（比如负荷）

m = LinearRegression().fit(X, y)     # 训练：找一条最贴合这些点的线
print(m.predict([[5]]))              # 预测：温度 5 时，负荷约 10
最重要的一个观念

机器学习不是“让电脑自己变聪明”，而是用历史数据拟合一个从输入到输出的映射。所以数据质量、特征选择、评估方式，比模型名字重要得多。这也是为什么本教程用两章讲数据、一章讲特征。

读不懂代码时，按这个顺序看

先看输入和输出，不看中间

这段函数接收什么、返回什么？知道这两端，中间只是加工过程。

遇到不认识的函数，先查它做什么，不要背参数

比如 shift(24)：查一次就知道是“整体下移 24 行”，比记住所有参数有用。

打印中间结果

在关键行后面 print(df.head()) 或 print(df.shape)，看数据在每一步长什么样。

删到最小可运行

把代码删到只剩 5 行还能跑，再加回一行，看哪一行改变了结果。这是定位问题最快的办法。

常见问题

Q1：数学要学到什么程度？
会加减乘除、百分比、平均数即可开始。时序部分会用到“平均、方差、分位数”，第 2 章会补；优化部分会用到线性方程，B4 会从零讲。不需要先学完微积分和线性代数。
Q2：完全没写过代码，要多久？
按每天 1 小时，两周能读懂本教程的代码；能独立改写需要 1~2 个月。关键不是看完语法，而是把第 2 章那段 30 行示例亲手跑通、改几个参数看结果变化。
Q3：需要 GPU 吗？
不需要。两个项目的模型在普通笔记本 CPU 上几分钟内跑完。只有做深度学习实验时才考虑 GPU，而本教程的结论并不依赖它。
Q4：报错搜不到怎么办？
把报错最后一行 + 你的代码片段一起搜；先确认数据形状（df.shape）和列名（df.columns）。80% 的报错是列名、类型、路径、空值四类问题。
